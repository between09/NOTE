# 🎓 授業ノートAI — Androidスマホ版 v1

スマホのブラウザだけで、

**録音 → 文字起こし → AI整理 → ノート表示**

まで行う試作版です。

## この版でできること

- 授業名・先生・日付を入力
- スマホのマイクで授業を録音
- OpenAIで日本語音声を文字起こし
- AIが以下に整理
  - 3〜6文の要約
  - 重要ポイント
  - 授業の流れ
  - 重要語句
  - 課題・提出物
  - 復習ポイント
- 元の文字起こしを確認
- ノートをJSONで保存

## スマホで使うための公開方法

このアプリは「Webアプリ」として公開する想定です。
HTTPSで公開すればAndroid Chromeから使えます。PWA化するとホーム画面にアプリのように追加できます。

### いちばん簡単な方法

1. GitHubにこのフォルダをアップロード
2. Streamlit Community Cloud等で `app.py` を公開
3. サーバー側のSecretsに
   `OPENAI_API_KEY = "あなたのAPIキー"`
   を設定
4. 発行されたURLをAndroid Chromeで開く
5. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」

## 大事な注意

APIキーをアプリの画面やスマホ側のJavaScriptに直接書かないでください。
この構成ではサーバー側のSecretsに置く前提です。

授業の録音は、大学・授業担当者のルールを確認してください。
他の学生の発言が入る場合は、特に扱いに注意してください。
